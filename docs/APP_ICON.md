# I See You app icon

The home-screen icon is an original generated smart-glasses illustration: ivory frames and blue lenses on a navy background. It contains no Ray-Ban or Meta wordmarks or logos.

The opaque 1024 × 1024 PNG is stored in `ISeeYou/Assets.xcassets/AppIcon.appiconset/AppIcon.png`. Xcode's AppIcon asset catalog supplies the iOS icon sizes and the system applies its corner mask. `project.yml` declares AppIcon as the app icon set; regenerate the project with XcodeGen after changing project settings.
